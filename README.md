# Currency Converter Application

A mobile application built in Flutter & Dart for currency conversion using a fixed exchange rate table.

## Features

- Support for Top 10 global currencies (USD, EUR, JPY, GBP, CNY, AUD, CAD, CHF, HKD, NZD).
- Real-time conversion update as amount or currency selection changes.
- Fixed exchange rate matrix with USD base rates.

## Setup & Testing

Run test suite:
```bash
flutter test
```

Run on device/emulator:
```bash
flutter run
```
